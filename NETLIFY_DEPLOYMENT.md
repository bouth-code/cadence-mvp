## Troubleshooting

### Build Fails
1. Check build logs in Netlify dashboard
2. Common issues:
   - Missing environment variables → Add via Site Settings
   - Node version mismatch → Verify in netlify.toml
   - Dependencies → Run `npm ci` locally to reproduce

### API Not Responding
1. Verify `CLAUDE_API_KEY` is correctly set
2. Check API key isn't revoked/expired
3. Review Netlify function logs

### Deployment URL Issues
1. Verify DNS is pointing to Netlify nameservers
2. Check Site Settings > Domain management
3. SSL certificate should auto-generate

---

## Rollback Strategy

### If Deployment Fails
1. Go to **Deploys** tab
2. Find last successful deploy
3. Click: **Actions > Publish deploy**

### If Code Needs Rollback
1. In GitHub: `git revert [commit-hash]`
2. Push to main: `git push origin main`
3. Netlify automatically rebuilds
